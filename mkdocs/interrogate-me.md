# Interrogate Me

!!! note

    Nothing is installed. There is no program, no browser extension, and no
    account. The rows below are the base set: what any website can already
    see the moment you connect, wherever that site is hosted. Your browser
    offers them on every visit, before you type a word or tick a box.

    A site with its own server can see further, because it watches the
    connection that actually delivered the page, including the TLS handshake
    this page has to read from a second request. Grant a permission, such as
    your location, camera, or microphone, and a site can see those too. This
    page asks for none of that.

    Browser Interrogator does not keep a copy. The values are read in your
    browser, shown here, and then dropped. Close the tab and nothing from
    the visit is stored.

    [How it Works](how-it-works.md) explains each lookup, including which
    requests leave the browser.
